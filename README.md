Como personalizar:

- Abra o arquivo c:\Site\index.html e altere os campos desejados.

Visualizar localmente:

- No Windows, abra o arquivo index.html no navegador.
- Ou rode um servidor simples (recomendado para testes de links):

```powershell
python -m http.server 8000
# depois abra http://localhost:8000
```

Se quiser, posso ajustar cores, fontes, layout ou fazer deploy estático.
